# Dataset Information

## 1. Dataset Name

Gene expression signature of cigarette smoking
and its role in lung adenocarcinoma development
and survival.

## 2. Dataset Accession Number

GSE10072

## 3. Dataset Source

NCBI Gene Expression Omnibus (GEO)

Website:
https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE10072

## 4. Organism

Homo sapiens (Human)

## 5. Dataset Type

Expression profiling by array (Microarray).

## 6. Platform

GPL96 - Affymetrix Human Genome U133A Array.

## 7. Dataset Size

The dataset contains 107 samples.

- 58 lung tumour tissue samples
- 49 non-tumour lung tissue samples

The supplementary raw data archive is approximately
375.3 MB.

## 8. Biological Importance

This dataset helps researchers understand gene
expression patterns associated with lung
adenocarcinoma and smoking.

## 9. Data Availability

The dataset is publicly available through
the NCBI GEO database.

## 10. Conclusion

GSE10072 is a useful public biological dataset
for learning gene expression analysis and
bioinformatics concepts.
