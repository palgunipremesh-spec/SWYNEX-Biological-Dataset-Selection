# SWYNEX-Biological-Dataset-Selection
biological dataset selection and documentation using a public NCBI GEO dataset

## Introduction

This project focuses on selecting and documenting
a public biological dataset for bioinformatics learning.

The selected dataset is obtained from the NCBI
Gene Expression Omnibus (GEO) database.

## Dataset Details

- Dataset ID: GSE10072
- Organism: Homo sapiens (Human)
- Data Type: Gene Expression Data
- Experiment Type: Expression Profiling by Array
- Platform: GPL96
- Number of Samples: 107

## Dataset Source

NCBI Gene Expression Omnibus (GEO)

https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE10072

## Research Area

Gene expression patterns in lung adenocarcinoma.

## Research Question

How do gene expression patterns differ between
lung tumour tissues and non-tumour lung tissues?

## Objective

To understand how publicly available gene expression
datasets can be used in bioinformatics.

## Conclusion

This dataset provides biological information that
can help us understand gene expression and its
importance in studying diseases.
